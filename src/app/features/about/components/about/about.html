O Dev to Dev nasceu do Front-End Quiz, um projeto pequeno com cinco quizzes de frontend. A ideia agora é maior: cobrir várias áreas do desenvolvimento e fazer cada pergunta ensinar alguma coisa, não só dar uma nota.

Toda pergunta traz a explicação de cada alternativa, e a página de cada quiz indica materiais para estudar o assunto a fundo. O que você erra volta para revisão, para que o conteúdo fique de verdade.

A central de recursos segue a mesma lógica: poucos itens, bem escolhidos, cada um com o motivo de estar ali.

Seu progresso fica salvo só neste navegador. Não há conta nem coleta de dados pessoais.
